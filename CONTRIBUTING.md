# Contributing to AgroDex

Thank you for wanting to contribute to AgroDex! To ensure a smooth collaboration process, please follow these guidelines.

## 🌿 Branch Naming Conventions

When creating a new branch to work on an issue, please use the following formats:
*   For features: `feat/your-feature-name` (e.g., `feat/login-button`)
*   For bug fixes: `fix/bug-description` (e.g., `fix/navbar-overflow`)
*   For documentation: `docs/short-description` (e.g., `docs/improve-readme`)

## 🛠️ Linting and Code Quality

This project uses ESLint to maintain uniform code quality. Before committing your changes, make sure your code does not contain any formatting or linting errors.

You can check for linting issues by running:
*   *Using npm:* `npm run lint`
*   *Using Bun:* `bun lint`

Please resolve any warnings or errors before pushing your code.

## 📥 Pull Request Process

1. Create a descriptive branch for your work.
2. Commit your changes with clear, concise messages.
3. Push your branch to GitHub and open a Pull Request against the `main` branch.
4. Reference the issue number you are resolving in the PR description (e.g., `Closes #4`).
